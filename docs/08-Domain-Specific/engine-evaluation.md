# TASK-002: engine feasibility evaluation

Date: 2026-11-01 (Asia/Calcutta). Status: bounded feasibility evaluation completed; production engine adoption conditional. Implementation is an isolated lab, not the application. Sources remain private and all document processing is on-device.

## Candidate comparison

| Candidate | Evidence | Outcome |
| --- | --- | --- |
| PDF.js + pdf-lib alone | pdf-lib public APIs do not edit/remove ordinary body text | Insufficient as the complete editing solution; no need to install for this comparison |
| MuPDF.js | AGPL/commercial distribution model | Not selected under private-source/free-first direction |
| PDFium through @embedpdf/pdfium 2.15.1 | Installed wrapper MIT license; bundled notices include BSD-style PDFium terms and Apache text; actual object-edit API exercised | Recommended candidate for next guarded native-text slice; full transitive license audit before distribution |
| Tesseract.js 6.0.1 + core 6.1.2 + local English data 1.0.0 | Apache-2.0 engine/wrapper; model package declares MIT; all assets supplied locally | Candidate for local OCR, not an automatic scan-layout reconstruction solution |
| Custom content-stream writer / paid SDK | Not implemented or purchased | Keep alternatives if guarded PDFium editing proves insufficient |

The PDFium wrapper README's brief license description is not a substitute for the bundled notices. Preserve both wrapper and engine notices; audit third-party components/model provenance before shipping. No legal-compliance certification is claimed.

Official references: [PDFium editing API](https://pdfium.googlesource.com/pdfium/+/refs/heads/main/public/fpdf_edit.h), [EmbedPDF package source](https://github.com/embedpdf/embed-pdf-viewer/tree/main/packages/pdfium), [pdf-lib limitations](https://github.com/Hopding/pdf-lib#limitations), [MuPDF FAQ](https://mupdfjs.readthedocs.io/en/latest/faq/index.html), [Tesseract source](https://github.com/naptha/tesseract.js). ## Decision and next gate

Proceed with PDFium as a provisional adapter for TASK-003 and guarded native-text experimentation. Do not yet advertise arbitrary PDF editing or multilingual fidelity. Before a user-editable native flow: glyph/mapping validation, overflow preview, transactional rollback, nested/rotated text handling, worker isolation and safe unsupported states. Before arbitrary scans: language assets, OCR review and background-aware reconstruction or explicit refusal. Before distribution: complete license/model notice audit, package/privacy/security tests and support matrix.

The proof establishes a viable free/local direction for supported cases. It does not establish that every PDF or every language can preserve exact formatting.
